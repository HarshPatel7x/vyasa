# docs

> Routing README for the project's substantial documentation. The root `README.md` is a thin
> entry point — project identity plus a router; the prose lives here. A signpost, not a
> destination.

## What lives here

- [overview.md](overview.md) — what vyasa is, why it exists, why the name "vyasa".
- [structure.md](structure.md) — the full project tree, what each component is and why, and how
  the tool will be used once `cli/` lands.
- [decisions.md](decisions.md) — the Decisions log: every structural call made during scoping,
  with reasoning, plus a provenance footer. This is the append-only home of every structural
  decision (the `Touches: D<N>` commit footer validates against it).
